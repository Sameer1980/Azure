In Azure for identity and access management we have Microsoft Entra ID .
In Databricks we have Unity Catalog.

First verify data security under Azure environment ( Microsoft Entra ID)
Then verify security under Databricks Unity Catalog.

Databricks Access Connector will help to connect from ADLS to Databricks environment.
We have to define the RBAC (Role-Based Access Control) under Azure environment and external location under the Databricks environment
for the Access Connector.

From ADLS :
Steps for connecting ADLS to Databricks.
1.Create a Resource Group(Eg: 'aconnector-grp')
2.Create a ADLS container.Eg: 'databricks-container'.Create a folder within the container 'testdata'. Upload some data sets.
3.Go to 'All Services' and search for access connector.('Access Connector for Azure Databricks').Click Create.
4.Give a name for the instance (Eg: 'aconnector')
5.Go to 'Managed Identity'. There are two types of Managed Identity. One is System assigned and another is User assigned. We will be using the System Assigned.
6.Go back to ADLS container . Choose 'Access Control(IAM)'
7. Under IAM we have to provide the role assignment. 'Add role assignment' .
8. Assign the 'Storage Blob Data Contributor' role to the Managed Identity member which is the Access Connector 'aconnector'.

From Databricks :
1.Create a new Catalog. Under Storage location -> 'Create new external location'.
2. Give a name to the external location, Storage type will be 'Azure Data Lake Storage' .
3. Give the url as :- 'abfss://testdate@azuretodatabricks1.dfs.core.windows.net'
4. Under Storage Credential 'Create New storage credential' .
5. Under Access Connector ID , copy the Access connector Id from Azure and paste.
   (Eg: '/subscriptions/5528779e-21aa-4306-8adc-3f7d8d45d4d7/resourceGroups/azuretoDatabricks/providers/Microsoft.Databricks/accessConnectors/aconnector')
6. Click Create.
7. Click 'Force Create' if required (due to 'Storage Blob Data Contributor' role one may not get all the access privileges)
8. Create a test notebook for validation. Provide this value -> %fs ls '%fs ls 'abfss://testdate@azuretodatabricks1.dfs.core.windows.net/'
9. Try to upload file into the ADLS container to validate .
10. Create a dataframe for further validation- 
df = spark\

Azure Data Factory to Databricks 
---------------------------------------------|
1. Create Azure Databricks notebooks and pipelines.
2. Create ADF resource.
3. Create a linked service for Azure Databricks.
4.Generating an access token.
5. Use a notebook activity in a pipeline .
6. Use parameters in a notebook.
7. Setting parameter values in a pipeline .
8. Finally, run a Azure Databricks notebook with Azure Data Factory.

A) Create a ADF instance .
B) From 'Orchestrate' or 'New' create a new pipeline instance.
C) From 'Manage' create a new 'Linked Services'.
D) New linked service --> Compute --> select Azure Databricks.
E) 
Name -> 'AzureDatabricks1'

Databricks workspace -> adf-databricks 
Authentication type -> Access Token

G) Give the cluster version - (Eg: 15.4 LTS)
