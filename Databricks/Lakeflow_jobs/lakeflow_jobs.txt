Orchestration - 
Jobs can run practically anything , Eg: pipelines in sequence , notebooks, control flow, conditional statements , etc.
Suppose I want to create a job that will orchestrate a notebook or two notebooks .So I will create two tasks . 
One task will run at 8:00 pm and after it's completion second task will run.
Or I have 3 notebooks . Notebook A will run and then after it's completion notebook B and C will run in parallel.

Go to Jobs & Pipelines and create a new task.
Name - Task-A
Type - Notebook
Source - Workspace
Path - <your path>
Notifications
Retries - Retries at most [1 time(2 total attempts)] and wait 15 sec. between retries.
Save Task .

Create another task.
Name - Task-B
Type - Notebook
Source - Workspace
Path - <your path>
Notifications

Run if dependencies -> By default it's 'All Succeeded' but if we want to run Task B on Task A failure we can use "All failed" or "At least one failed".

Create another Task.
Name - Task-C
Type - Notebook
Source - Workspace
Path - <your path>
Notifications

Suppose we want to run Task-C parallely with Task-B then we need to modify the 'Depends On' field , change it to Task-A .

Run job.

CONDITION BASED JOBS .
---------------------------------------------------------------

IF conditions 
I want to run Task-B if it's weekend and Task-C if it's weekday .

First of all delete both tasks Task-B and Task-C.

Create a new Task which is based on If/else condition, 'IfSaturday'.

In the Condition box insert a dynamic value reference , Eg: {{job.start_time.is_weekday}} or {{job.start_time.iso_weekday}} == 7 
Click 'Save Task'.

Create another task which is based on notebook., Task-B . By default it's connected to the True condition of the 'If/else' task . Map the path to Notebook-B.
Create another task which is also based on notebook , Task-C . Change it's dependency to the False condition of 'If/else' task. Map the path to Notebook-C.

Run the job.

LOOPS BASED JOBS.
----------------------------------------------------------------------
Delete Job-A.
Create a new job from scratch.
Create a new task 'LoopTask' . Click the icon above to create a looping task.
Or create a new task based on For-each loop. 'MyLoop'.

Inputs -> [1,2,3,4,5]

Concurrency-> This is optional . So if we want to run multiple iterations of the task parallely we can set this value , Eg: 5 so five iterations will run in parallel.
Else by default one iteration will end then another will begin.

Click on the button 'Add a Task to loop over'.  And name the task as 'LoopedTask'. Map the task path to 'Notebook-A'.
Save Task.

Delete the first task 'LoopTask'. 
Run the job . 'LoopedTask' will run the 'Notebook-A' five times (5 iterations).
